## 尚存问题

1. **证据检查造成可见漏判。** 7条被程序从relevant降为uncertain，因为模型将原文引用缩写、拼接或替换标点，未通过逐字匹配。其中包括Peakflo FDE招聘、AiStudio招聘、明确FDE项目教程。它们不是全部“模型捏造”；需要支持多个连续原文片段，或让模型返回可定位的短引用，不能简单取消证据校验。
2. **聚合偏保守。** 51条对应51组。保留独立项目符合要求，但没有证明系统能识别应当合并的重复内容。英国/伦敦几条相似招聘值得下一步核查是否同一岗位，当前不应仅凭标题认定同一岗位。
3. **相关性仍有边界放宽。** 部分个人README、企业合作新闻和泛RAG学习内容进入相关集合；这可能符合宽泛技能/客户部署范围，但对具体FDE实践的信息密度有限。应区分直接FDE内容与相邻工程参考，而非一律视为同等直接相关。
4. **摘要/宣传文本干扰。** 某YouTube视频标题主要讨论其他工具，摘要带通用FDE课程宣传，被判断为相关；另一条相似摘要被判不确定，说明边界仍不够一致。应区分内容主题与描述中的通用推广文案。
5. **中文渠道召回较弱。** 抖音两次收费搜索只返回1条且信息不足；当前直译搜索词不够自然。下轮可在配置阶段生成中文行业常用表达，不在本轮运行中动态改词。
